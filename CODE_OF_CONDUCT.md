# Code of Conduct

We welcome people of different backgrounds and experience levels. Be respectful, focus feedback on the work, and help others reproduce and resolve problems. Harassment, personal attacks, discriminatory language, and sharing another person's private data are not acceptable.

Maintainers may edit or remove abusive contributions and restrict participation when needed to keep the project safe. Report conduct concerns privately to the maintainers through GitHub's repository contact options; do not publish sensitive details in an issue. Security vulnerabilities belong in [private security reports](SECURITY.md).
